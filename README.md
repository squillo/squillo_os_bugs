# Squillo OS Bug Reports

Use this repository to file bugs for Squillo OS.

## Before you file a bug

Please check whether the issue has already been reported. If you find an
existing report for the same problem, add any extra details there instead of
opening a new issue.

## How to file a bug

Open a new issue and include:

- A short, clear title
- The Squillo OS version you are using
- Your device or hardware details
- Steps to reproduce the problem
- What you expected to happen
- What actually happened
- Any error messages, logs, screenshots, or photos that help explain the issue

## Tips for a useful report

- List the exact steps in order
- Say whether the bug happens every time or only sometimes
- Mention any recent updates or changes made before the bug started
- Include anything that makes the problem easier to reproduce

Clear bug reports make it easier to investigate and fix problems quickly.
